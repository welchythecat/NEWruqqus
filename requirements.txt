# Ruqqus -- pinned runtime dependencies
#
# Target: Python 3.12+ (tested on 3.12/3.13).  Install with:
#
#     python -m venv .venv
#     source .venv/bin/activate          # Windows: .venv\Scripts\activate
#     pip install -r requirements.txt
#
# Every line here is a package the code imports directly, plus gunicorn
# (production server) and redis (the Flask-Caching / Flask-Limiter storage
# backend).  Transitive dependencies -- click, itsdangerous, blinker,
# webencodings, typing-extensions, ... -- are deliberately left to pip's
# resolver so a security fix in one of them is picked up without a pin bump.
# If you need a byte-for-byte reproducible install, run
# `pip freeze > requirements.lock.txt` right after installing.

#     supported.  Start with `-w 2` and add more only if you measure a need.
